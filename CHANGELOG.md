# Changelog

All notable changes to `@codewithrajat/universal-player` are documented here.
This project follows [Semantic Versioning](https://semver.org/) and uses
[Changesets](https://github.com/changesets/changesets).

Published — npm registry returns `0.0.1` for `@codewithrajat/universal-player`.

## 0.0.1 (published)

### Patch Changes

- Initial enterprise skeleton:
  - Headless `UniversalPlayer` core with immutable state and three event styles.
  - Native video/audio, image, HLS, DASH, YouTube, Vimeo and generic embed engines.
  - `<universal-player>` custom element with custom/native controls, theming,
    i18n and WCAG 2.2 AA-oriented markup.
  - React, Vue 2.7/3, Angular, Svelte 4 and Svelte 5 adapters.
  - Feature contracts for captions, audio tracks, quality, speed, PiP,
    fullscreen, AirPlay, cast, thumbnails, chapters, playlist, resume, live,
    ads, analytics, mini-player and VR.
  - ESM-only packaging, strict TypeScript, Vitest + Playwright, publint, attw,
    tarball allowlist checks, Changesets and GitHub Actions release automation.
