    Class AngularUniversalPlayer

    Framework-neutral Angular controller.

    Angular libraries built with a generic bundler cannot emit partial compilation metadata, so a precompiled @Component would not be AOT-safe. Consumers therefore own the decorated standalone component and forward lifecycle calls to this controller (see examples/angular).
