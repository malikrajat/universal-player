## The five decisions

1. Full UI, native controls, or custom chrome?
2. Which source shape (URL, File, chunked, embed)?
3. Which conditional peer/browser API do you need?
4. Who owns assets and persistence?
5. What is your browser test matrix?

## A note on claims

This book does not claim WCAG conformance, DRM, SSR rendering, OCR, real HLS/DASH verification, Safari/mobile testing or numeric bundle budgets. The repository does not prove them.
