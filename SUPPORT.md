## Bugs

Use the bug report template and include:

- Package version
- Browser and OS
- Framework and version (React/Vue/Angular/Svelte/vanilla)
- Media source type (native, HLS, DASH, YouTube, Vimeo, image)
- Minimal reproduction or a public stream URL
- Console errors and network failures

## Security

Never report vulnerabilities publicly. See [SECURITY.md](./SECURITY.md).

## Commercial support

There is no commercial support contract for this project. Community support is
best-effort, with no SLA.
