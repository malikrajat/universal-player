## Repository root

```
universal-player/
├── docs/                      # Documentation (this folder)
├── src/                       # Library source
├── tests/                     # Vitest unit and browser tests
├── scripts/                   # Packaging and import validation
├── .changeset/                # Changesets
├── .github/                   # CI, release workflow, issue templates
├── .vscode/                   # Editor recommendations/settings
├── build/                     # Generated repository folders (build:repo)
├── coverage/                  # Generated coverage output
├── dist/                      # Generated build output
├── _docs/                     # Generated TypeDoc HTML (_docs/api, git-ignored)
├── _examples/                 # Internal example apps (not published)
├── CHANGELOG.md               # Canonical release history
├── CODE_OF_CONDUCT.md
├── CONTRIBUTING.md
├── LICENSE
├── README.md                  # Package landing page
├── SECURITY.md
├── SUPPORT.md
├── package.json
├── pnpm-lock.yaml
├── tsconfig.json
├── typedoc.json
├── vite.config.ts
└── vitest.browser.config.ts
```

`dist/` is generated by `pnpm run build`; `coverage/` by
`pnpm run test:coverage`. Neither is edited by hand.

### Boundaries

| From         | May import                                                       |
| ------------ | ---------------------------------------------------------------- |
| `core`       | `core`, `features` (pure helpers), `adapters` (engine factories) |
| `adapters`   | `core` types, `adapters/shared`                                  |
| `features`   | `core` types and utilities                                       |
| `ui`         | `core`, `features`, `ui`                                         |
| `frameworks` | `core` and their framework package                               |
| `entries`    | anything public                                                  |

`core` must never import `ui`, `frameworks` or a framework package. This is the
invariant that keeps `/core` headless.

## `docs/` layout

```
docs/
├── README.md                  # Documentation hub
└── *.md                       # Every canonical page, flat, no subfolders
```

All documents live directly in `docs/` as single files. There are no
subfolders: FAQ, concepts, examples, getting-started, migration, theming,
troubleshooting and feature guides are all root-level files.

every target exists and that no source/test files leak into the tarball.

### Repository folder

```bash
pnpm run build:repo             # build, then assemble build/universal-player/
pnpm run build:repo my-name     # use a custom folder name
pnpm run build:repo my-name -- --force   # replace an existing folder
pnpm run repo my-name           # re-assemble without rebuilding
```

`build:repo` copies (never moves) `dist/`, `docs/`, `README.md`, `LICENSE`,
`SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`,
`CHANGELOG.md`, `package.json` and `.npmrc` into `build/<folder-name>/`.

Every other root-level content folder is discovered automatically, so new
folders such as `_examples/` or `examples_directly_/` are picked up without a
script change. Code, tooling and generated directories are skipped:
`src/`, `tests/`, `scripts/`, `node_modules/`, `dist/`, `build/`, `coverage/`,
`_docs/`, `playwright-report/`, `test-results/`, hidden folders, and nested
`node_modules`, `dist`, `coverage`, `.angular`, `.svelte-kit` and `.vite`
folders.

Nothing is mandatory: if a path does not exist it is reported as skipped and the
remaining entries are still copied, so a partial repository folder is produced
instead of aborting. The same applies to a copy that fails.

The folder name defaults to the package name without its scope and is written
under the git-ignored `build/` directory.

## Where to make a change

| Change                   | Files                                                                          |
| ------------------------ | ------------------------------------------------------------------------------ |
| New player option        | `src/core/types.ts`, `src/core/player.ts`, element attribute handling, docs    |
| New UI control           | `src/ui/element.ts`, `src/ui/styles.css`, `PlayerControl` union                |
| New engine               | `src/adapters/<name>/`, `src/core/engines.ts`, `MediaProvider` union           |
| New survey question type | `src/core/types.ts`, `src/features/survey/survey.ts`, `src/ui/survey-panel.ts` |
| New framework adapter    | `src/frameworks/<name>/`, `src/entries/<name>.ts`, `package.json` export       |
| Packaging change         | `package.json`, `vite.config.ts`, `scripts/check-pack-contents.mjs`            |
| Docs                     | `docs/` + `README.md` + `CHANGELOG.md`                                         |
